# Поток 51

Прототип расчёта кредитного лимита на пополнение оборотных средств малого
бизнеса по **карточке счёта 51** из 1С.

Карточка счёта 51 показывает движение по всем расчётным счетам клиента во всех
банках и содержит корреспондирующие счета — то есть экономическую квалификацию
каждого платежа, уже выполненную бухгалтером клиента. Это снимает главное
ограничение транзакционного скоринга, который видит обороты только в своём банке.

Прототип разбирает карточку, отделяет реальную операционную выручку от транзита,
внутригрупповых переводов, заёмных денег и возвратов, считает 15 риск-индикаторов
и выдаёт лимит с полной трассируемостью каждой цифры до строк исходного файла.

для сверки собственной реализации.

## Быстрый старт

```bash
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
```

Сгенерировать синтетические карточки (8 профилей, включая транзитную схему,
обналичивание и схлопывание оборота):

```bash
.venv/bin/python -m synth.generate --out data/synthetic
```

Посчитать лимит по одной карточке:

```bash
.venv/bin/python -m potok51.cli data/synthetic/01_wholesale_healthy.xlsx --industry wholesale --html report.html
```

Поднять веб-сервис:

```bash
.venv/bin/uvicorn potok51.api:app --reload --port 8051
```

Тесты:

```bash
.venv/bin/python -m pytest -q
```

## Конвейер

```
READER → NORMALIZER → VALIDATOR → CLASSIFIER → LINKER → CLEANER → INDICATORS → LIMIT → REPORTER
```

| Модуль | Файл | Назначение |
|--------|------|-----------|
| Чтение | `potok51/readers/card51_xlsx.py` | автопоиск шапки, двухуровневые заголовки, склейка многострочных операций |
| Целостность | `potok51/validate.py` | 8 проверок, включая сходимость сальдо и совпадение с итогами файла |
| Классификация | `potok51/classify.py`, `potok51/rules/` | корсчёт (первичный) + ~70 правил по назначению платежа |
| Сопоставление | `potok51/link.py` | внутренние переводы, дубли эквайринга, детектор транзита |
| Очистка | `potok51/clean.py` | мост от валового притока к очищенной выручке и свободному потоку |
| Индикаторы | `potok51/indicators.py` | 15 светофоров, T1–T6 по логике 18-МР |
| Лимит | `potok51/limit.py` | минимум из четырёх ограничителей, множители флагов, 7 стоп-факторов |
| Отчёт | `potok51/report/` | автономный HTML и выгрузка Excel |

Все калибруемые пороги собраны в `potok51/config.py` — это единственное место,
где меняется поведение модели.

## Статус

Прототип. Все примеры и демонстрационные отчёты построены на **синтетических
данных**, которые генерирует `synth/` — реальных клиентских карточек в
репозитории нет и быть не может. Готовые примеры отчётов и документы в PDF
лежат в [docs/pdf](docs/pdf).

## Границы прототипа

Модель экспертная, на правилах: обучающей выборки дефолтов нет, поэтому PD не
рассчитывается и разделительная способность не измерена. Индикаторы, взятые из
Методических рекомендаций Банка России 18-МР, используются как кредитные факторы
риска, а не как основание для отказа в обслуживании счёта. Решение прототипа
рекомендательное и не заменяет решение уполномоченного органа банка.
